# Weather data (.epw)

Put an EnergyPlus weather file (`.epw`) in this folder and point the *File Path*
parameter feeding **LB Import EPW** in `ArchSim Script.gh` at it.

ArchSim was developed against the Vancouver Intl Airport CWEC 2020 file:

- [CAN_BC_Vancouver.Intl.AP.718920_TDY-CWEC2020v2.zip](https://climate.onebuilding.org/WMO_Region_4_North_and_Central_America/CAN_Canada/BC_British_Columbia/CAN_BC_Vancouver.Intl.AP.718920_TDY-CWEC2020v2.zip)
  (unzip and use the `.epw` inside)

Weather files for any other location are available free at
[climate.onebuilding.org](https://climate.onebuilding.org/) or
[EnergyPlus weather data](https://energyplus.net/weather).
