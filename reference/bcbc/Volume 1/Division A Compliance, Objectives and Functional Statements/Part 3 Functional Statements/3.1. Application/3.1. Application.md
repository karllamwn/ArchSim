# BCBC 2024 — Division A, Part 3 Functional Statements
## Section 3.1 — Application of Part 3

---

### 3.1.1. Application of Part 3

**3.1.1.1.(1)** Part 3 applies to all buildings governed by this Code.

---

### 3.1.1.2. Limitations on Application of Specific Functional Statements

The following limitations restrict which functional statements apply to particular building types:

**(1)** Functional statement **F56** (Noise Protection) applies only to buildings that contain a **dwelling unit**.

**(2)** Functional statements **F73** and **F74** (Accessibility) do not apply to:
- **Detached houses**, semi-detached houses, duplexes, triplexes, townhouses, row houses, boarding houses, lodging houses, or rooming houses
- Buildings of **Group F, Division 1** occupancy
- Buildings that are not occupied on a **daily or regular basis** by their users

---

### Summary Table — Functional Statements with Restricted Application

| Functional Statement | Restriction |
|---------------------|-------------|
| F56 — Noise Protection | Buildings containing dwelling units only |
| F73 — Barrier-Free Path of Travel | Not houses/duplexes; not Group F Div 1; not non-daily-occupied |
| F74 — Usability | Not houses/duplexes; not Group F Div 1; not non-daily-occupied |

All other functional statements (F01–F55, F57–F72, F75–F101) apply to **all buildings** governed by this Code, subject to the specific provisions of Division B that link to them.
