# BCBC 2024 — Division A, Part 3 Functional Statements
## Notes to Part 3

> Notes have **no legal effect** (per 1.1.3.1.), but provide explanatory guidance on the intent of functional statements.

---

## A-3.2.1.1.(1) — Numbering of Functional Statements

### Numbering Gaps

The functional statement numbers in Section 3.2 contain **apparent gaps** (e.g., F07–F09 are absent between F06 and F10; F14–F19 are absent between F13 and F20). These gaps are **intentional**.

The BCBC maintains a **master numbering system** shared across all BC Code documents:
- **Book I** — BC Building Code
- **Book II** — BC Building Code (reserved/future)
- **BC Fire Code**

Numbers are reserved in this master list so that each functional statement has a **unique, consistent code** across all documents in the BC Code family. A number reserved for the Fire Code, for example, will not be reused in the Building Code, even if the corresponding building code requirement has no directly equivalent functional statement.

This ensures that when referencing a functional statement code (e.g., F43 — combustion products), the same code consistently refers to the same function regardless of which BC Code document is being consulted.

### Practical Implication

When reviewing a Division B provision's attributed functional statements (listed in the right-hand margin of Division B), the F-codes listed are drawn from this master list. The fact that F07–F09 do not appear in Division A of the Building Code does not mean those functions are unaddressed — it means those F-codes are assigned to Fire Code provisions or are reserved.

Designers should **not** interpret gaps in functional statement numbering as gaps in coverage. All intended building performance functions are addressed either in the Building Code or the Fire Code.
